# V2X Message Lab

**Learn, Build, Encode, and Decode SAE J2735 Messages.**

An open-source, browser-only learning laboratory for SAE J2735 (SEP2024). Release 1 covers the
**Basic Safety Message (BSM), Part I**: enter real vehicle measurements, watch each value become a
standardized J2735 integer, encode it with a real ASN.1 UPER codec, inspect every bit, and decode
captured payloads.

> SAE J2735 is © SAE International. This project cites section numbers and contains original
> explanations only; it does not include the standard or SAE’s ASN.1 files.
> See [docs/STANDARDS_AND_COPYRIGHT.md](docs/STANDARDS_AND_COPYRIGHT.md).

## Modules

| | Module | What you can do |
|---|---|---|
| A | Learn SAE J2735 | Nine progressive lessons with diagrams, interactive examples and exercises |
| B | BSM Generator | Enter measurements (with units, examples, ranges, “unavailable”), or load 5 consistent scenarios |
| C | Transformation explorer | Raw value → SI unit → LSB scaling → rounding → range handling → J2735 value → receiver value → quantization error |
| D | Structure explorer | Vehicle values, J2735 values, ASN.1 tree/module and JSON — synchronized, with field detail panels |
| E | UPER encoder | Real UPER bytes for `BasicSafetyMessage` and `MessageFrame`; hex, binary, sizes, download, copy |
| F | Bit-level explorer | Click any field to see its exact bits, offset, width and how it is recovered |
| G | Decoder | Hex / binary file / samples; rejects invalid, truncated, malformed, foreign or wrapped payloads |
| H | Round-trip comparison | Inputs → values → bytes → decoded values → recovered measurements |
| I | Research vehicle ID | Keep labels like `UA-CAR-07` in metadata and exportable logs, never in the BSM |
| J | Reference explorer | Search all BSM Part I messages, data frames and data elements |

Beginner / Engineering / Advanced modes control how much detail is shown. Light and dark themes,
keyboard navigation and phone layouts are supported.

## Quick start

```bash
npm install
npm run dev        # open the printed localhost URL
```

| Command | Purpose |
|---|---|
| `npm test` | Vitest unit + UI tests |
| `npm run typecheck` | strict TypeScript check |
| `npm run build` | production build into `dist/` |
| `npm run preview` | serve the production build |
| `npm run export:vectors` | export encoder output for independent validation |
| `npm run validate:independent` | run the Python cross-validation (after `pip install -r tools/validation/requirements.txt`) |
| `npm run export:samples` | regenerate `samples/` from the scenarios with the real codec |

Requires Node.js 20+ (CI uses 22). Validation requires Python 3.10+.

## How correctness is established

The codec is this project’s schema-driven implementation of ITU-T X.691 (unaligned PER), written in
TypeScript so that it runs in the browser and can report verified bit positions
([why](docs/CODEC_EVALUATION.md)). It is verified by:

- hand-derived X.691 bit-pattern tests and J2735 conversion tests (incl. the §11.5 speed table);
- **two independent ASN.1 toolchains** (asn1tools, pycrate): 814 encodings byte-identical, 814
  decodings value-identical;
- **4 096 independent bit-position checks** for the Bit Explorer;
- **129 real BSM MessageFrames** from the USDOT JPO ODE project, whose Part I values were decoded by
  an asn1c codec generated from SAE’s ASN.1: identical values, byte-exact re-encoding.

Details, what each test proves, and what remains unverified: [docs/VERIFICATION.md](docs/VERIFICATION.md).
Requirements and traceability: [docs/TRACEABILITY.md](docs/TRACEABILITY.md),
[docs/FIELD_TRACEABILITY.md](docs/FIELD_TRACEABILITY.md).

## Samples

`samples/` contains, for each scenario, the input dataset, the encoded `BasicSafetyMessage` and
`MessageFrame` (`.uper` binary + hex JSON) and the decoder output — all generated by the codec.
Independent real-world payloads are in `tests/fixtures/reference-vectors.json`.

## Limitations (Release 1)

- BSM only; other message types inside a MessageFrame are identified and skipped.
- Part II and regional extensions are preserved but not interpreted, and are not generated.
- No IEEE 1609.2 / WSMP / PC5 processing — payloads must be extracted first.
- Not a conformance-test tool; application standards such as SAE J2945/1 were not available.
- Where J2735 is silent, implementation choices are documented (rounding ties away from zero,
  secMark truncation, yaw rate “unavailable” sent as 0 with a warning).

## Deployment

GitHub Actions builds, tests, cross-validates and deploys to GitHub Pages on every push to `main`.

such as `https://USERNAME.github.io/v2x-message-lab/` (hash routing, relative assets).
